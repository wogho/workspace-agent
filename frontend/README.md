# 업무 웹 프런트엔드

React + TypeScript + Vite로 만든 장부형 업무 화면의 공개용 소스다.

## 화면 구성

- `src/main.tsx`: 상품 장부·회계 장부·계산기/정책 탭과 로그아웃
- `src/Ledger.tsx`: 상품 상태·재고·가격·마진 관측과 사용자 결정 기록
- `src/Accounting.tsx`: 월별 대조·판매/정산·세금 문서·입금·카드 매입·부가세·문서함
- `src/Calculator.tsx`: 가격 계산과 정책 표시
- `src/api.ts`, `src/acctApi.ts`: 상대 경로 API 계약과 CSRF 요청 처리
- `src/styles.css`: 라이트·다크 테마와 반응형 표/패널 스타일

## 공개 범위

이 디렉터리는 화면 구조와 API 계약을 설명하기 위해 비민감하게 정리한 버전이다.
API 서버, 인증정보, 원본 상품·주문·고객·금융 자료, 매입처 식별자, 운영 정책 저장소는
포함하지 않는다. 매입처와 관측자 정보는 화면에서 일반화해 표시하며, 데이터는 런타임
백엔드가 제공할 때만 표시된다.

## 로컬 빌드

```bash
npm ci
npm run build
```

빌드 결과는 `dist/`에 생성되며, 배포 환경의 상대 `/api/` 경로를 사용한다.
