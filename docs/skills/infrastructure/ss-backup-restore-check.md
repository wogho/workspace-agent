# `ss-backup-restore-check` 공개 계약

인프라 데이터 담당이 일일 백업과 정기 복원 시험의 결과를 확인하는 공개 계약이다.
백업 원문, 저장 위치, 암호화 키, 고객·메일·주문·금융 자료와 내부 명령은 공개하지 않는다.

## 확인 범위

- 최신 일일 백업의 성공 여부와 보존 기간
- 최근 백업 크기가 평소 범위에서 벗어났는지 여부
- 정기 복원 시험의 성공·실패와 마지막 확인 시각
- 데이터베이스, 자동화 설정, 메일 보관, AI 직원 문서·스킬, 회계 문서 등
  승인된 백업 대상의 누락 여부
- 재해복구 묶음의 최근 성공 여부

## 안전 규칙

- 백업 파일을 풀어 고객정보·키·비밀을 출력하지 않는다.
- 암호화 키와 저장소 자격증명을 읽거나 전송하지 않는다.
- 무결성 결과와 복원 시험 결과만 요약해 보고한다.
- 백업 스크립트·타이머·보존 정책을 직접 수정하지 않는다.
- 실패·대상 누락·보존 위반은 원인 후보와 영향, 사용자에게 필요한 결정을 함께
  보고하고 안전 상태를 유지한다.

## 공개 결과 형태

```text
status: ok | warning | failed
last_backup: 가림 시각
restore_test: passed | pending | failed
coverage: complete | needs-review
retention: within-policy | needs-review
```

실제 파일명, 경로, 해시, 크기, 로그 원문과 저장소 이름은 비공개 운영 화면에서만
확인한다.
