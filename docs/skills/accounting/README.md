# 회계팀 공개 스킬 계약

운영 환경에는 회계팀 전용 스킬이 연결되어 있지만, 원문에는 내부 명령·저장 위치·
권한 경계·업무 데이터 처리 규칙이 포함될 수 있어 공개 저장소에 복사하지 않는다.
이 디렉터리는 역할과 입력·출력 계약만 비민감하게 정리한 공개 문서다.

| 계약 | 담당 | 공개 범위 |
|---|---|---|
| `accounting-web.md` | 회계팀 공통 | 정본·증빙·금액 기록 원칙 |
| `naver-sales-settlement.md` | Henry | 판매·정산 조회와 대조 |
| `purchase-sales-reconcile.md` | Henry | 매입·판매 건수 대조 |
| `tax-invoice-monthly.md` | Henry | 월 세금 문서 대조 |
| `vat-return-yearly.md` | Henry | 연간 신고 자료 취합 |
| `accounting-documents.md` | Nora | 문서 분류·보관 |
| `card-purchase-import.md` | Nora | 카드 원본 표준화 |
| `deposit-match.md` | Nora | 입금·정산 대조 |
| `month-close.md` | Nora | 월 마감 점검 |
| `jangbu-standardize.md` | Ella | 경리 원본 표준화 |

실제 계정, 고객·거래 데이터, 원본 증빙, 인증정보, 자동화 워크플로 설정은 공개하지 않는다.
