# 상품 장부 품질 공개 계약

2026-10-05~06 서버의 상품 변동·오탐 내역·탐지 제외 변경을 공개 가능한 규칙으로
요약한다. 실제 상품명, 상품번호, 판매 채널, 가격, 판매자와 관측 원문은 공개하지 않는다.

## 탐지 제외와 사용자 대기

- 사용자가 명시적으로 탐지 제외한 상품은 자동 판정 결과보다 우선해 제외 상태로 남긴다.
- 사용자가 대기시킨 상품은 정기 경쟁가 비교를 반복하지 않고, 사용자가 가격을 정할 때까지
  대기 상태로 표시한다.
- 직접 관리 대상이나 확인되지 않은 매입 정보는 자동 판매 후보로 승격하지 않는다.
- 가격·재고·상품명 변경은 제안과 실제 반영을 분리한다. 장부 결정만으로 스토어 변경이
  완료됐다고 간주하지 않는다.

## 상품 변동

공개 화면은 최근 기간의 변동을 다음 종류로 집계한다.

- 신규 등록·발굴
- 판매 재개·판매 상태 변경
- 가격 변경
- 품절·삭제
- 상품명 변경
- 사용자 결정

각 기록에는 가림 상품 라벨, 일반화한 변경 설명, 담당 역할, 성공·실패 결과와 시각만
반환할 수 있다. 내부 상품번호, 스토어 URL, 판매자 계정, 원본 요청·응답은 반환하지 않는다.

## 오탐·미탐 품질

오탐은 잘못 채택한 경쟁 정보나 가격이고, 미탐은 실제 경쟁 정보를 놓친 판정이다.
서버는 현재 상태를 기준으로 심각도를 계산하고 다음 상태를 구분한다.

```text
OPEN · HOLD · FIXING · RESOLVED · REJECTED
```

공개 화면은 심각도, 판정 유형, 일반화한 원인, 사용자 판단 필요 여부와 처리 상태만
읽기 전용으로 표시한다. 정정 실행, 가격 적용, 원본 경쟁 정보 열람은 운영 화면의
권한 게이트와 사용자 결정 뒤에만 가능하다.

## 증거 원칙

- 판정은 관측 시각·정책 버전·원본 근거의 연결이 없으면 완료로 확정하지 않는다.
- 자동 검증 결과는 사용자 제보와 구분해 감사 이력에 남긴다.
- 같은 유형의 반복 오류는 개별 상품 문제가 아니라 규칙 품질 문제로 승격해 보고한다.
- 화면·Slack·로그에는 고객정보, 키, 결제정보, 자격증명과 외부 채널 식별자를 보내지 않는다.
