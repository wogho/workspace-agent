# 현재 서버 업데이트 공개 요약

기준일: 2026-10-10  
기준 문서: `project.md` 0.7.9~0.7.15, 결정 기록 Z163~Z168

이 문서는 운영 서버에서 확인한 최근 변경을 공개 가능한 기능·정책·계약으로만 요약한다.
실제 계정, 상품·주문 자료, 외부 판매 채널, URL, 인증정보, 원본 로그와 실행 스킬은 포함하지
않는다. 공개 저장소는 운영 서버의 복제본이 아니라 비민감한 구조 설명 레이어다.

## 실행기와 복구 경계

- 화면 조회·작업은 역할별 Chrome 세션과 `ss-*` 업무 도구를 사용한다. 이전 보조 브라우저
  엔진은 현재 운영 경로에서 제외하며 다시 연결하지 않는다.
- 브라우저 진단 로그와 임시파일·HTTP 캐시는 제한된 크기로 관리하고, 운영 로그는 암호화된
  보관 경계를 사용한다.
- 자원·서비스·타이머·정기 업무·작업 정체·관측 지연·반영 실패·회계 불일치·재해복구 상태를
  감시한다. 동일 사건은 묶어서 알리고 회복 시 회복 사건을 남긴다.
- 디스크 포화나 무선 연결 장애처럼 인프라 장애가 발생하면 증거 보존, 안전한 공간 확보,
  서비스·핵심 API 확인, 데이터 복원 시험 순서로 복구한다. 거래 재실행이나 재발송은 상태와
  증거를 확인하기 전 자동으로 수행하지 않는다.

## 모델 사용량과 실행 기록

- 모델 계정별 사용량은 주기적으로 읽어 주 계정 소진, 백업 전환, 회복 상태를 확인한다.
- 한도 부족·소진·백업 전환은 인프라 운영 알림으로 전달하며, 신규 발굴은 사용량이 부족한
  동안 안전하게 쉬도록 한다.
- 사원 실행마다 입력·출력·생각 토큰과 캐시 읽기를 구분해 기록하고, 업무별 실행 수·오늘·
  어제·최근 7일 합계·평균을 읽기 전용 화면에서 확인한다. 토큰 값이 제공되지 않은 실행은
  임의의 수치로 채우지 않는다.
- 실행 계정·토큰·메일 주소·내부 상태 파일은 공개 API나 저장소에 노출하지 않는다.

## 상품 관측과 발굴 흐름

- 기존 상품의 1차 관측은 코드 기반 읽기 경로가 담당하고, AI 직원은 링크 이상·상품 식별
  불일치·가격 급변·재고·지역 활성화 문구 미확인·보안 확인 등 예외와 회차 보고를 담당한다.
- 보안 확인을 자동으로 통과하거나 체크하지 않는다. 연속 차단이 기준을 넘으면 코드 관측을
  멈추고 남은 대상은 이전의 AI 읽기 경로로 인계해 기록한다.
- 관측에는 시간 상한과 페이지 간 간격을 둔다. 제한에 걸린 대상은 품절·0원·정상으로
  추정하지 않고 다음 회차 또는 예외 확인 대상으로 남긴다.
- 새 상품은 발굴 → 시장 비교 → 플랫폼 등록의 순차 흐름으로 처리한다. 한 회차 목표는
  등록·판매 중인 후보를 일정 수 확보하는 것이며, 앞 회차가 끝나기 전 다음 회차를 중복
  시작하지 않는다.
- 시장 비교 주기는 신규·판매·위험·비판매 상태에 따라 달리 적용하고, 매입가 변동·재고
  회복·주문 발생 같은 사건이 있으면 최소 간격을 지켜 앞당긴다. 검색은 여러 검색어
  변형으로 교차 확인한다.
- 관측 파일은 대상 선정 전에 가져와 최근 확인 대상을 중복 처리하지 않도록 한다.

## 가격·포트폴리오·회계

- 공통 가격 계산기는 예상 노출가·등록가·순이익을 구간별 규칙으로 계산하고, 충분한
  순이익 구간에서는 등록가도 시장 최저가보다 낮게 둘 수 있다. 가격 하한과 근거 없는
  계산을 함께 적용한다.
- 리뷰·판매 실적·경쟁 관측·구매 신호를 이용해 상품 포트폴리오를 분류한다. 인기도와
  예상 순이익이 모두 기준을 넘는 후보는 별도 전략 후보로 표시하지만 자동 확정하지 않는다.
- 주문별 회계 화면은 예상 정산·예상 마진과 실제 정산·실제 마진을 분리한다. 취소·반품·
  환불 조정과 구매 인계 근거가 없으면 확정 마진을 만들지 않는다.
- 사용자 결정의 실제 반영 여부는 별도 상태로 추적하고, 반영 전 결정·중복 결정·가격 급등은
  안전 중단 또는 재확인 대상으로 둔다. 외부 반영 후에는 조회로 결과를 재확인한다.
- 지휘본부 점검 자료에는 상품 포트폴리오·가격 계산·경쟁 관측 감사 자료를 추가하되 원본
  고객·결제·상품 식별정보는 마스킹한다.

## 공개 범위

이 저장소에 반영할 수 있는 것은 위와 같은 역할, 상태, 흐름, 마스킹된 화면 계약이다.
다음은 계속 서버 로컬에만 둔다.

- 비밀 환경변수, 토큰, 인증서, 브라우저 세션·쿠키, 암호화 credential
- 메일 원문, 고객 식별자, 주문·결제·키 원문, 외부 채널의 계정·가격·구매 자료
- 백업 원본·복구 증거·운영 로그·캐시·데이터베이스
- 실제 구매 실행 스킬과 내부 작업 프롬프트

관련 공개 화면은 `frontend/src/Dashboard.tsx`, `frontend/src/Ledger.tsx`,
`frontend/src/Logic.tsx`의 비민감 UI 계약을 기준으로 하며, 서버의 실제 설정값을 복사하지
않는다.
